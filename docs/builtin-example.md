# 内置示例与安装初始化

0.2.5 内置 18 秒、1280×720、30 fps 的电影感品牌短片，中文和英文各提供一份连续旁白与逐句字幕。五条轨道分别保存字幕、原生渐变花字、HTML 动画、原创海岸画面和 WAV 旁白。每次初始化创建独立会话，不改写已有作品。

三幕分别呈现海岸全屏开场、暖色画面组装和品牌收尾。构图参考 Xinshen 的产品介绍模板（左侧大标题、分层信息、错峰入场）和活动预告模板（暖色、细线装饰），未复制其资源或文案。HTML 文字逐字/逐词入场，渐变高光按源时间扫过；原生花字使用 flower-frost / flower-gold 的多层渐变材质。标题有位移、缩放和透明度关键帧，海岸画面有缓慢推进关键帧；这些曲线均保存在普通工程数据中，可继续编辑。正向、反向拖动均按绝对源时间采样。

配音一次生成整段，不在三幕之间插入空白。八条字幕独立可编辑，暖色场景提供深色字幕衬底。旁白随包分发，初始化不运行 TTS、ASR 或下载模型。海岸图为原创生成素材，另作为可替换的图片轨道；HTML 中的预览缩图自包含，不请求外部资源。

## 使用入口

- MCP：initialize_demo({locale:"zh"})，返回普通会话快照和 previewUrl；Agent 自动打开该地址。
- 客户端：client.initializeDemo({locale:"en",name:"Welcome"})。
- CLI：videocut-web --demo --open --port 0；英文追加 --demo-locale en。
- SKILL：[initialize-demo](../plugins/videocut-local/skills/initialize-demo/SKILL.md)，随 npm 和独立插件分发；videocut-web --print-setup-skill 可直接读取。

官网中英文安装提示词固定 npm 发布版本，要求读取并执行此 SKILL、初始化固定作品并自动打开客户端预览。即使宿主不能持久安装 SKILL，也按其内容执行展示。初始预览停在标题完整可见的 1.5 秒；第一次播放从片头开始，手动拖动后则从选择的位置播放。素材目录留空时，先创建专用 ffclip-projects 目录，仅将它设为授权根目录；导入个人素材时再选择目录。当前聊天未加载新注册的 MCP 工具时，提示词使用持久 CLI 进程先展示作品。

示例预览延后可选视觉模型对话框，不修改原有许可或同意状态。只有作品实际使用的内置 JPEG 和 WAV 文件获得读取权限，包所在目录不成为新的授权根目录。完整 vcutweb 保存会复制两种媒体，并保留 HTML、文字配方、变量、字幕和关键帧。

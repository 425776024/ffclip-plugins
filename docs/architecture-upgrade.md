# Web 编辑器架构升级记录

本次实现保持桌面 **Project Format 1**；`.vcut` 是目录。Web JSON 只作为不持久化会话投影。FFmpeg/FFprobe 是改造前已有的本机依赖，本次改为可选后备，不打包、不下载、不作为启动要求；容器元数据默认纯 JavaScript 读取。不增加 FFmpeg WASM、NodeAV、`@mediabunny/server` 或 `@mediabunny/aac-encoder`。

## 文档与命令

`editTimeline` 从冻结基线创建候选，只在整个批次结束后校验，避免两个相邻片段移动时的中间重叠错误。UI/MCP 均经 `/commands`，服务端前后两次检查版本；任何验证失败不发布。`EditTransaction` 暴露 begin/update/commit/cancel/invalidate。拖动草稿不写服务端，松开只提交一条批次，Esc/外部版本取消。

候选使用写时复制，保留未修改分支的对象身份；手势更新从固定基线计算，不再为每次指针事件复制整个作品。撤销/重做共享服务端 `CommandHistory`，保存稳定对象 ID 路径的正反增量补丁，按 16 MiB 字节上限回收。UI 与 MCP 的操作进入同一历史；冲突或验证失败不消费历史。显式 `update_session` 全量替换作为导入/恢复边界清空历史，不冒充普通编辑命令。

统一的时间映射以整数 ticks 表达 source、placement 和 itemLocal。恒速用桌面 constantRatePpm。关键帧采用桌面插值语义；裁剪/分割切片保留原曲线，包括缓动曲线的控制点。分组与音画关联参与选择扩展，波纹编辑在同一事务内计算最终位置。失去相邻关系的转场在同一事务移除。

关联音画的裁剪、恒速和分割共用时间变化；分割后左右各自建立独立关联。单选分组/关联成员会选中完整闭包，修饰键按闭包增减选择。波纹范围可选所选轨道、所选及同步轨道或所有轨道；同步轨道开关与编辑锁分离。锁定参与轨道或删除范围穿过未选内容时整个操作拒绝。特效按稳定实例 ID 排序，转场参数与时长修改保留实例 ID 并重新检查源素材余量。

属性描述供模型验证、属性面板与 MCP 共用。未知作品字段和不能映射的原生功能显式拒绝。原生桥接器直接调用 SDK，复杂文字指纹在 SDK 编码规范化后生成；重新打开时校验内容和配方摘要，不保存私有 JSON sidecar。

文字、时间、视觉、音频和动态效果参数使用同一描述，包含类型、范围、单位、默认值、适用对象、可动画性与 media/layout/effect/composite/audio 更新影响。MCP 的静态属性与模板参数输入范围由这些描述生成；实例参数通过 `get_properties` 查询。公开 `EditorCommand` 为可判别联合类型，动态 Inspector 在描述验证后构造具体命令；公开声明由实现及 authored DTO 类型生成。

## 计算与缓存

Mediabunny 固定为 1.61.0 核心包。媒体索引与浏览器能力分开，采样返回实际 PTS；预览连续游标、缩略图游标、导出游标分离。媒体任务支持优先级、合并在途请求、多消费者取消与过期结果释放。缓存按字节计量且回收 VideoFrame/ImageBitmap；波形按有限块保存分声道 extrema 和多级索引，完整 PCM 不常驻。

时间轴按可见时间、轨道范围及小量预加载绘制；每格采样经统一时间映射。波形缩放只查询数值区间。项目尺寸、视口和预览像素预算独立；交互自动降分辨率不作为同画质加速证据。

渲染计划共享属性/动画求值。媒体、文字和转场统一进 WebGPU compositor；设备与管线复用，资源按存活节点释放，基础场景可回退 Canvas2D。GPU 内存数字不等于进程总内存；不承诺浏览器端零拷贝。

文字只读取本机已安装字体，不附带或下载字体包。Node 延迟扫描系统标准目录，通过不透明 ID 提供字体；TTC 只提取选中字体供浏览器使用。普通文字与模板共用字体选择规则，预览和导出读取同一份本地字体；Format 1 保存系统字体引用，不复制字体文件。保存的字体身份无法在本机匹配时明确提示，避免静默换字形。

## 输出

导出使用冻结版本及同一 SceneRenderer，按帧索引计算时间，并使用同一分块音频混合器。浏览器编码、浏览器视频加本地音频编码、完整本地编码三档共同使用这一帧流；本地编码仅复用原有 FFmpeg。Node 验证块序号/偏移、RGBA 帧尺寸及 PCM 样本数，通过背压限制在途数据，先写临时文件，再无覆盖发布。

MCP 无浏览器执行者时返回预览地址；关闭网页、取消或错误时清理临时文件。浏览器真正能力探测决定配置能否编码。源容器可读取不保证其中编码可解码。

浏览器 AAC 编码通过短编码/解码探测建立实际编码延迟，再用负 PTS 与 MP4 edit list 对齐；Opus 从编码器输出的 OpusHead 读取 preskip。首期 WebM 使用毫秒时间基，且当前封装 API 无末尾 DiscardPadding，解码器可能保留一个编码包内的尾部补样；不把它描述为样本级精确裁尾。

## 验证证据

自动化检查位于 `tests/*.test.mjs`，覆盖核心批量顺序、回滚、事务失效、分数帧时间、关键帧切片、缓存回收、去重/取消、数值波形、分块混音、HTTP 文件与版本协议、真实 FFmpeg 编码、原生 Format1 保存/打开、npm 与插件安装包。

浏览器实际运行入口：

- `tests/browser-render.html`：统一合成、文字配方、效果/转场、混合模式、编码封装、输出重新解码与像素比对。
- `tests/browser-media.html`：29.97/VFR 的 PTS 参考、连续/随机解码、取消、DPR 组件、双声道和一小时波形、缓存冷/热数据。

私有本地证据写入 `.local/architecture-qa/`，不分发测试素材或报告。成功构建不代表浏览器、GPU、扬声器或桌面 Flutter UI 验收。原生桥接器重开验证不等于桌面 UI 已实际打开。运行结果及未覆盖范围记录在同目录的报告中。

## 明确边界

SDR 首期；曲线变速、保调变速、嵌套时间轴、HDR、复杂3D/人脸深度特效后置。柔光对应 Core Image bloom 的 Web 近似，跨后端像素不承诺相等。效果参数动画受桌面 catalog 合同限制；不修改原生合同绕过不支持项。尚不能导入桌面完整能力集；无法无损表示时拒绝。

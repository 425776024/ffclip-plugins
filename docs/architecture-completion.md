## 已确认约束

- 保存、打开统一桌面 Project Format 1 `.vcut` **目录**；不提供 v2、迁移或持久化 Web JSON 旁路。
- 不打包或下载 FFmpeg/FFprobe；已有本地程序可选后备，不引入 FFmpeg WASM、NodeAV 或相关 Mediabunny 扩展。
- 普通文字与模板只用本机系统字体，不附带字体文件。
- 2026-09-29 用户明确取消桌面 GUI 对照验收；仍须 SDK 原生 Format 1 双向格式校验。
- 曲线变速、保调、嵌套时间轴、HDR、复杂 3D 和人脸/深度效果维持原计划的后续范围，不计入本期交付。

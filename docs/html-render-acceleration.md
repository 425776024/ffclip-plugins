# HTML 动画导出加速

不改变作品的分辨率、帧率、HTML、粒子或阴影。

## 通用浏览器路径

HTML 截图使用两条独立串行捕获通道，与现有两帧预取衔接；同一 DOM 不会并发跳时。
静态状态签名包括 DOM、CSSOM 和滚动位置，状态一致时复用内存帧。画布、图片、原生 CSS/WAAPI 动画、自定义字体和未知外部资源等情况保守禁用跨时间复用。
帧缓存上限 64 MiB，不写磁盘。此路径仍使用 PNG，适用于各平台和通用多轨合成。

## 可选 macOS 原生路径

构建：

```sh
node scripts/build-html-renderer.mjs
```

启动服务时设置 `VIDEOCUT_HTML_RENDERER` 为生成的 `.local/bin/ffclip-html-renderer` 绝对路径，或向 `startServer` 传入 `htmlRenderer`。
仅 macOS 需要 Swift 编译器；默认服务和其他系统不依赖此程序。

原生路径支持一个覆盖全画布、全时长、未变换的 HTML 片段，以及最多一条无淡入淡出的普通音频。多轨叠加、效果、转场、变速和 WebM 使用通用合成器。

WKWebView 按共享时间推进代码渲染，快照像素直接复制到 CVPixelBuffer，交给 VideoToolbox 硬件 H.264 编码。没有逐帧 PNG 压缩、Base64 或 HTTP 帧传输；仍有快照光栅化和像素复制，并非零拷贝。
预览使用 Chromium，原生导出使用 WebKit，两者字体和抗锯齿可能略有差别。

相同静态状态复用上一张内存像素缓冲；整个动画不变时，复用有界内存中的编码视频，单独重新合并音频。
编码视频缓存上限 256 MiB，LRU 淘汰，进程关闭清空，不存在磁盘缓存。HTML、参数、画布、帧率、源区间或渲染器版本变化会使缓存失效。
最终 MP4 和首次编码的临时 MP4 仍是正常导出文件；临时文件完成后清除，不写截图序列。

原生导出独立于浏览器标签生命周期。通用浏览器导出仍要求打开作品页面。

- 同一服务、同一动画再次导出：1.162 秒，命中内存编码缓存。

- 两次 PNG 帧数、HTTP 帧传输字节均为 0；音频为 AAC 48 kHz 双声道。
- 首次导出与此前浏览器输出文件时间推算的约 231.65 秒相比收益有限；此前数字不是同场计时基准。
- 25、50、70 秒解码帧已检查；不代表 WebKit 与 Chromium 像素完全一致。

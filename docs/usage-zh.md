# VideoCut 使用说明

## 编辑与保存

将视频、音频或图片导入素材区，拖到时间轴。选中片段即可修改文字、位置、效果和时长。按空格播放；使用撤销恢复操作。

保存时选择“导出 → 保存完整工程”，保留生成的 `.vcutweb` 目录。下次通过“打开工程”继续编辑。

## 让助手编辑

安装提示词会让助手根据当前环境配置 MCP 工具连接。连接完成后，可以直接说：

- “裁掉开头两秒，再加一个标题。”
- “把这段配音转成字幕。”
- “导出当前作品为 MP4。”

如需手动配置，命令是 `videocut-web`，参数为 `--mcp --port 0 --root /你的素材目录`。按当前助手支持的方式添加本地 MCP 服务；已有配置应保留。

## 导出

点击“导出”，选择 MP4 或 WebM，等待完成。导出期间保持页面打开。

## 可选模型

自动字幕、配音、视觉分析需要另外下载模型。内置示例无需模型。下载完成后，本地推理处理你的素材。

## 从源码运行

```sh
git clone https://github.com/425776024/ffclip-plugins.git
cd ffclip-plugins
npm install
npm run build
node dist/bin/videocut.mjs --demo --open --port 0
```

文本渲染器附带源码、预编译 WASM 和哈希记录。可选原生桥接需要另行提供桌面 SDK。官网 `ffclip/` 目录未开源。

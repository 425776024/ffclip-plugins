# 内置文字模板外观

内置库包含 10 款花字、10 款文字气泡和 10 款动画文字。模板仍使用原生
`composition.json`、`animation.ir.json`、`effect.program.json` 与资源清单，文字可编辑。
保留对应参考包的布局、字号、分层、描边宽度、偏移、纹理映射、图集划分、
九宫格切片和资源尺寸。参考图片像素不进入发布包。

花字分别继承不同的材质结构，避免两套母版换色：

| 模板     | 参考结构        | 外观场景                               |
| -------- | --------------- | -------------------------------------- |
| 蜜桃灯牌 | flower-style-03 | 珐琅灯牌、暖色灯珠，庆祝标题           |
| 薄荷拼贴 | flower-style-38 | 折纸切面、薄荷色图集，清新创意标题     |
| 热力火焰 | flower-style-29 | 连续熔金流纹、多层暖光，热血标题       |
| 紫雾软糖 | flower-style-24 | 糖晶、紫粉糖面，甜蜜日常               |
| 电波蓝   | flower-style-12 | 定向蓝色拉丝、霓虹边缘，科技与出发场景 |
| 香槟金箔 | flower-style-14 | 金箔质感和金属立体层，庆典标题         |
| 奶油纸刻 | flower-style-04 | 撕边手工纸、干笔装饰，生活手账         |
| 漫画爆点 | flower-style-10 | 爆炸轮廓、规则网点，漫画强调           |
| 墨色留白 | flower-style-05 | 米纸纤维、墨绿字面，文艺旁白           |
| 冰川银   | flower-style-33 | 冰晶纹理、银蓝切面，冬季旅行           |

气泡使用对话框、云朵、讯号面板、折角便签、票券、括号、胶囊、像素框、
蓝图框和缎带十种图案。平铺包的切片中心保持连续，防止透明留边重复成横向接缝。
历史气泡执行图没有调度底板，`composeRecipe` 在共用的预览/导出合成阶段补入
隐式合成；磁盘上的原生模板格式和布局保持不变。

动画包括浮现、聚拢、翻页、逐字打印、弹跳、侧滑、回弹、波浪、呼吸和摇摆。
时间采样由原生动画 IR 驱动，循环和回退寻帧不依赖墙上时钟。

文件保存在 `artwork/`，构建脚本读取它们作为原生资源替换图。

其余切片、描边、网点、纸纤维和装饰采用场景专用的确定性图形生成器。
外部动画仍保留原来视频资源和包装格式，以新生成的运动光环替换视频像素。

重建：`npm run build:text-presets`，然后 `npm run build`。
可通过 `VIDEOCUT_FFMPEG` 指定 FFmpeg 路径。结构和像素回归检查位于
`tests/authored-text-presets.test.mjs`；截图与真实预览图记录在 `.local/text-presets-qa/`。

VideoCut browser ASR uses Transformers.js 3.8.1 (Apache-2.0), including its bundled ONNX Runtime Web 1.22.0-dev.20250409-89f8206ba4 (MIT). Source: https://github.com/huggingface/transformers.js/tree/3.8.1 and https://github.com/microsoft/onnxruntime . Runtime JavaScript is unmodified except removal of source-map pointers. Licenses are in licenses/.
Whisper Base model resources are downloaded separately from the fixed onnx-community/whisper-base_timestamped revision listed in the service manifest. Whisper is MIT licensed: https://github.com/openai/whisper . Audio stays on the local machine; only model installation contacts Hugging Face.

The same offline Transformers.js/ONNX Runtime assets are used by VideoCut local visual understanding. FastVLM-0.5B-ONNX weights (Apple AMLR) are installed separately only after initialization consent, from pinned revision ca35eb9373f8a8761df0855fca19dea330f2407a. Model and license: https://huggingface.co/onnx-community/FastVLM-0.5B-ONNX . No weights are bundled and no cloud inference is used.

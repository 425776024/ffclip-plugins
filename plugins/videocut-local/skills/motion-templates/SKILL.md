---
name: motion-templates
description: Author editable flower text templates and deterministic HTML or GSAP motion graphics for VideoCut, then mix them with local media on the existing timeline. Use for custom titles, transparent graphics, HTML animation imports, or reusable motion templates.
---

Use the bundled VideoCut tools to author graphics in the same editing session as video, images and audio. Read [video-editing](../video-editing/SKILL.md) for session, media, preview and export operations.

Template generation and HTML import are Agent workflows through MCP. The editor offers template selection and ordinary value editing; it has no HTML import, source-editing or JSON-editing controls. Generate or adapt the document yourself and call `add_html_clip`; do not ask the user to paste code into the editor. The same MCP contract can be used by Codex, WorkBuddy and other MCP-compatible assistants.

Call `list_motion_templates` to inspect the available native components and HTML runtime before choosing a representation.

Follow `nativeComposition` from that tool. Added `backdrop` or `animation` components are supported only when `base` is `flower-style-03` or `flower-style-38`. Cube, printer and studio/external bases can be selected as their original templates or as base-only recipes; adding background or animation components to those graphs is rejected. The six built-in presets retain their original supported behavior. A shipped component appearing in `parts` does not make every cross-combination valid.

- For flower text built from shipped native materials, backgrounds and letter animations, use `add_text` with a built-in `template` or a custom `template.recipe`. Keep the text editable. Select `base`, optional `backdrop` and optional `animation` from the returned components; do not invent unshipped components. Example: `{ "id": "my-flower", "version": 1, "recipe": { "base": "flower-style-38", "backdrop": "bubble-nine-slice", "animation": "anim-lua-letter-transform" } }`. This composes existing native packages; it does not accept arbitrary Lua or native shader programs. Custom recipes remain editable in `.vcutweb`, MP4/WebM and native `.vcut` roundtrips through the updated bridge (capability `customTextRecipes:1`). Use `save_project` to preserve the entire project without a native bridge.
- For custom DOM, SVG, CSS or GSAP graphics, create an `html-clip`. Read [the HTML contract](references/html-clip.md) before authoring or importing. Adapt [the transparent GSAP lower third](assets/gsap-lower-third.html) when useful.

Native flower templates use their own typography by default. Omit plain-text `fontSize`, `color` and font overrides when adding a template; size and place the result with its shared visual scale/position properties. To override template color or font size, use `template.style.color` and `template.style.fontSize`; native saving requires the updated bridge capability `textTemplateStyles:1`. Text content remains editable.

HTML clips focus on graphics. Arrange the cut’s video, images and audio on existing media tracks; decorative image and font resources may belong inside the graphic. HTML clips use ordinary video tracks, so shared placement, transforms, effects, trim, split, constant speed and undo/redo remain available. A newly added HTML clip defaults to a top video track named “HTML 动画”; pass an existing video `trackId` to arrange adjacent graphics and media. Same-track overlaps require separate tracks.

For a local HTML file, call `add_html_clip` with the session `id` and an absolute `path` inside an authorized root, plus its source `width`, `height` and `duration`. Relative JS, CSS and image resources are frozen into the authored document during import. For inline generation, pass the complete `html` payload instead. Use integer ticks for `duration`, `start` and `length`: one second is 120000 ticks. Animation callbacks receive seconds.

Keep user-facing text, colors, font choices and numeric settings editable. Static body text and simple values in style blocks or quoted inline styles are parsed into the inspector. For values controlled by JavaScript, expose primitive `html.variables` and read them from `window.variables` or `context.variables`; use meaningful keys such as `title`, `subtitle`, `color`, `fontFamily` and `fontSize`. Keep generated code and animation internals out of user-facing names and descriptions. Complex CSS expressions and arbitrary JavaScript constants are not inspector controls.

Support Chinese/English i18n for template library names, inspector labels, tooltips, accessibility labels and feedback through the editor's shared `src/editor/i18n/messages.mjs` catalog and `useI18n().tr`. The UI follows the computer's preferred language via `navigator.languages`/`navigator.language`, updates on `languagechange`, and uses Chinese for `zh` variants and English otherwise. Localize built-in placeholder content when a new preset is inserted; preserve its editable fields and deterministic animation. Use the user's explicitly requested language for authored titles, subtitles and narration. Never translate existing clip content, user-defined field names or imported HTML on a UI language change, and keep variable keys and template IDs stable.

Read `get_session` before `edit_timeline` and pass the returned `version`. Use raw `add_html_clip` or `set_html_clip` for atomic authoring changes. `set_html_clip` replaces the full HTML payload on that one item while preserving its source range and placement; its new duration must still cover the item’s source out-point. Splits carry independent copies of the authored payload.

Open the session preview, sample the graphic near its entrance, middle and exit, and revisit an earlier time after seeking forward. Drag the playhead in both directions and play the mixed timeline. When an export is requested, inspect the encoded output as well as the live preview. API success, screenshots and tests establish different evidence; report only what was observed.

HTML rendering needs installed Chrome/Chromium or `VIDEOCUT_CHROMIUM`. The Codex preview calls the local renderer; it does not need to execute authored HTML inside the preview page. MP4/WebM export flattens HTML with the other tracks and retains its alpha during compositing. Transparent whole-video export is not added. Use `save_project` to persist HTML clips and their variables in a complete portable `.vcutweb` directory. Custom flower recipes also roundtrip through the updated native `.vcut` bridge. HTML clips remain unsupported in native `.vcut`; do not promise native HTML roundtrips or full HyperFrames capability parity from this path.

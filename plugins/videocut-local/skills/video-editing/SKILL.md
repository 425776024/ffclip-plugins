name: video-editing
description: Edit local video through VideoCut tools with an editable live browser preview. Use for importing video, audio and images, local speech recognition and automatic captions, adding text, trimming, splitting, arranging clips, adjusting transforms and sound, or exporting a local cut.
---

Use the bundled VideoCut MCP tools. The model performs the editing; no second chat UI or external video service is required.

For installation onboarding or the built-in example, use [initialize-demo](../initialize-demo/SKILL.md): call `initialize_demo` and automatically open its returned preview URL. It supplies editable HTML animation, flower titles, packaged narration and captions without model downloads.

For custom flower templates, transparent HTML graphics or GSAP animations, use [motion-templates](../motion-templates/SKILL.md) and keep media on the existing tracks.

The editor supports Chinese and English i18n and follows the computer's preferred language exposed by `navigator.languages` (falling back to `navigator.language`): `zh` variants display Chinese; English and other languages display English. Keep UI labels, tooltips, accessibility labels and status messages in the shared `src/editor/i18n/messages.mjs` catalog and use `useI18n().tr` for display. Respond to `languagechange` without reloading the session. Locale changes must not rewrite existing project names, titles, captions, narration or imported media names. Use the user's requested content language when authoring text; UI locale is only a default for new built-in content, not an instruction to translate their work. Preserve stable tool names, IDs and serialized values across locales.

1. For a new work request, call `create_session` with a short readable `name` derived from the user's request. Continue an existing session only when the user supplies its preview link/local project directory or asks to continue a cut. Use `list_sessions` to find it by name, `previewUrl` or `projectPath`; do not guess between ambiguous matches. If a supplied `.vcutweb` or `.vcut` directory has no live session, use `open_project`. Save the returned internal `id` and `previewUrl`.
2. Open `previewUrl` with the available browser tools so the user can inspect the same temporary session. Do not navigate an active user-owned edit to a blank root page.
3. Call `list_files` in an authorized local directory, then `add_media` once per source. Use actual returned paths and item IDs. Never invent a user's media or upload it externally. If paths are outside authorized roots, explain how to add a root to the plugin configuration.
4. Insert editable text with `add_text`. In `add_text` and raw session JSON, time uses 120000 integer ticks per second. In `edit_timeline`, time fields explicitly ending in `Seconds` are ordinary seconds.
5. Read `get_session` immediately before `edit_timeline`, and pass its `version`. Prefer atomic edit batches over replacing the full JSON. `trim_clip` chooses source in-point and duration while retaining timeline start. `split_clip` returns `rightItemId`. `move_clip` moves a complete clip. Same-track overlaps fail. Keep video, audio and image/text overlays on suitable separate tracks. Track index 0 is the top visible layer; use `reorder_track` to place an image above a video. Use `set_audio` to avoid unintended double sound. `get_properties` describes shared attributes and supported effect/transition templates. Use `move_clips` for grouped/linked selections, `set_speed` for constant speed (pitch changes), and `set_keyframe` for supported properties. Transitions need adjacent clips and source handles.
6. Existing browser previews update via SSE; do not reload after each edit. Verify both the rendered project version and the visible preview. Use `preview_control` for seek/play/pause. A delivered command is not playback proof: `get_preview_status` must show an open client, matching command sequence, the current project version, advancing media `currentTime` and decoded video frames. If audio autoplay is blocked, click Play once in the browser or ask the user to do so. State separately whether sound was actually heard.
7. Save/export only as requested with `save_project`, `render_video` or `export_project`, using the reviewed current version and authorized output directory. Keep the session preview open for every video export: the browser supplies the shared compositor, with WebCodecs or the existing local FFmpeg for encoding. `get_render_status` and `cancel_render` inspect/cancel tasks. Without an attached page the server returns BROWSER_REQUIRED and previewUrl. Use `save_project` for a complete portable `.vcutweb` DIRECTORY, preserving media, HTML source/variables, editable flower recipes, effects, keys and frozen template resources. It requires no native bridge and supports relocation and service restart. Use `open_project` to reopen either format. `export_project` writes the desktop Project Format 1 `.vcut` DIRECTORY through the configured format bridge, with no JSON sidecar or replacement native format. The updated bridge preserves custom flower recipes; HTML clips require `.vcutweb` saving or MP4/WebM export.
8. Return the live preview link and concrete verification result. Do not claim full ChatCut feature parity, audible playback, or native desktop acceptance from API success alone.

Sessions are temporary and remain alive only while the local MCP process runs. A normal visit to `/` starts empty; the returned `/projects/作品名称` link reuses the explicit session. Same-named cuts receive numeric suffixes. Renaming updates the readable link while old links still reach the same cut for the life of the service. Legacy `/?session=…` links remain accepted. Present the readable preview URL to the user, not the internal session ID. `projectPath` is the actual local `.vcutweb` or `.vcut` directory after opening/saving, or null for unsaved cuts; never invent a local directory for an in-memory cut. Original media remain on disk. No automatic draft library is created.

## Local narration

Use `list_voices` to inspect installed Kokoro models and Chinese/English voice IDs. Browser speech synthesis uses WebGPU/WASM and requires no Python or cloud TTS. Model installation is a separate, explicit download: when the user requests speech synthesis and the model is missing, explain the listed model size and use `install_tts_model` for the selected dtype and voice. Poll `get_tts_model_status`; `cancel_tts_model_install` stops a download. Do not download every voice by default.

Open the session `previewUrl` before calling `synthesize_speech`, read the latest session version, and pass `id`, `version`, `text`, `voice`, `speed`, and optional `startSeconds`/`trackId`. The tool returns a job immediately; poll `get_tts_status` until completed, conflict, cancelled or error. Keep the browser open during inference. `cancel_tts` stops a running job. Missing browser/model errors retain a recovery code and preview URL; they are not successful synthesis.

By default the generated WAV is added as an ordinary audio clip. `insert:false` generates a file without modifying the timeline. A conflict retains the generated `asset.path`; reread the project and use `add_media` to insert it once at the desired location. Preserve generated WAV files because saved projects reference them. Verify playback through `preview_control`/`get_preview_status`, and distinguish audio generation from sound actually heard. Kokoro does not return verified word-level caption timestamps; do not fabricate subtitle timing.

## Local speech recognition and captions

ASR is an agent capability through MCP, with no editor button, model selector or manual installation flow. It always uses Whisper Base. When the user asks to transcribe audio/video or generate captions, open the existing session `previewUrl`, import the source if needed, and read `get_session` for its current version. Call `transcribe_speech` with `id`, `version`, and exactly one `itemId` or `assetId`; use `itemId` for a trimmed timeline clip so captions follow its source range, timeline start and constant playback rate. `assetId` recognizes the whole source, starting captions at zero unless `startSeconds` is supplied. Optional `language` defaults to `auto`; prefer `zh` or `en` when known. Audio remains local.

The first recognition automatically downloads and SHA256-verifies the fixed Base resources (about 209 MB) into a persistent cache. No separate installation tool or model choice is needed. `get_asr_model_status` inspects this cache. Use the default `backend:auto` for WebGPU with WASM fallback. Keep the preview page open while polling `get_asr_status` until `completed`, `conflict`, `cancelled` or `error`; `cancel_asr` stops recognition and an unused download. A missing browser returns `BROWSER_REQUIRED` and `previewUrl`. Source audio is limited to 60 minutes per task; trim long sources into separate clips. Reverse clips must be recognized from their original asset.

`insert:true` is the default: model timestamps become ordinary editable text clips on one subtitle track, undoable together. `insert:false` returns timed text without modifying the project. Returned `segments` use timeline seconds in `{text,start,end}`. On `conflict`, the text and segments remain in the job; read the fresh version, review alignment, then use `edit_timeline` with one `add_subtitles` operation and those segments. Silence completes with an empty result and adds no track. Check real speech, timing and the resulting preview; do not treat successful model download as successful recognition.
